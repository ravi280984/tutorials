# Demos

Demos are runnable companions to tutorials. Each demo should be self-contained and include:

- a focused `README.md` with its purpose, prerequisites, run steps, and expected result;
- a local dependency or project file when external packages are required;
- no committed credentials, generated data, virtual environments, or model weights;
- a link back to the related tutorial.
