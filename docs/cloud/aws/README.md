## Prerequisites for hands-on topics

- An AWS account with appropriate IAM permissions
- AWS CLI configured with short-lived credentials or identity federation
- A clear cleanup plan for resources that can incur charges

Never commit access keys. Prefer IAM roles and temporary credentials for automation.
