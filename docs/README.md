# Tutorials

The documentation is organized as a set of learning paths rather than a catalog of disconnected files.

| Path | Focus |
| --- | --- |
| [AI](ai/README.md) | How modern AI applications represent language, retrieve knowledge, use tools, and coordinate agents |
| [Cloud](cloud/README.md) | Cloud foundations and governed landing zones across providers |
| [DevOps](devops/README.md) | Continuous integration and repository automation |

Within each path, numbered files define the suggested reading order. Provider-specific or advanced material lives in a named subfolder.
